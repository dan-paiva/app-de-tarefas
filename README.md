# 📝 App de Tarefas (To-Do)

Meu primeiro projeto de programação: um aplicativo de lista de tarefas
feito com **HTML, CSS e JavaScript puro** (sem frameworks).

🔗 **[Ver o app funcionando ao vivo »](https://dan-paiva.github.io/app-de-tarefas/)**

## ✨ Funcionalidades

- ➕ Adicionar tarefas
- ✅ Marcar tarefas como concluídas
- 🗑️ Remover tarefas
- 🔍 Filtrar por: todas / ativas / concluídas
- 💾 As tarefas continuam salvas mesmo ao fechar o navegador (`localStorage`)

## 🚀 Como rodar

Não precisa instalar nada. Basta abrir o arquivo `index.html` no navegador.

## 🧠 O que aprendi neste projeto

- Manipular o DOM (criar e atualizar elementos da página com JavaScript)
- Trabalhar com eventos (`submit`, `click`, `change`)
- Usar arrays e métodos como `.map()`, `.filter()` e `.find()`
- Guardar dados no navegador com `localStorage`
- Organizar um projeto em arquivos separados (HTML / CSS / JS)

## 🛠️ Tecnologias

HTML5 · CSS3 · JavaScript (ES6+)
